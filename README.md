# Dokumentasi Workshop Day 1: Building with AI, Managing Change with GitHub

**Nama lengkap:** Rava Nayla Ryanti Pribadi

**Kelompok:** 25 My Talking Tom

## Deskripsi
Repository ini berisi dokumentasi kegiatan workshop **"Building with AI, Managing Change with GitHub"** (Day 1), yang disampaikan oleh Nugi Farhan, Senior Product Designer. Isinya catatan materi, rangkuman, dan hasil praktik selama workshop.

## Tujuan
- Menyimpan dan merapikan dokumentasi workshop secara daring di GitHub.
- Melatih penggunaan Git dan GitHub: repository, commit, dan push.
- Menjadi tempat belajar ulang materi prompt engineering dan version control.

## Kegiatan Workshop yang Didokumentasikan
Workshop Day 1 membahas dua topik utama:
1. **Prompt engineering**: cara menulis instruksi untuk AI agar hasilnya tepat, relevan, dan layak dipakai.
2. **Git dan GitHub**: mengelola perubahan dan berkolaborasi lewat version control.

Praktik utamanya: membuat aplikasi **Student Task Planner** dengan bantuan AI, lalu mengunggahnya ke GitHub.
