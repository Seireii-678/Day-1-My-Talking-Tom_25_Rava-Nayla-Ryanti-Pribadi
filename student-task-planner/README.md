# Student Task Planner

A simple task planner for first-year students. Built with HTML, CSS and vanilla JavaScript. No libraries.

## Files
- `index.html`: page structure
- `style.css`: layout and look (responsive)
- `script.js`: sample data, filter, and "mark as completed" logic

## Run
Open `index.html` in a browser. No server needed.

## Test
1. Click each checkbox: the title is struck through and the summary count changes.
2. Click **Pending** / **Completed** / **All**: the list filters correctly.
3. Complete every pending item, then open **Pending**: an empty message appears.
4. Resize the window below 480px: the layout stays readable.
